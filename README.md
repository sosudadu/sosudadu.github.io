# My Resume Desktop

macOS 데스크톱 스타일의 인터랙티브 웹 이력서 템플릿입니다.

## 이력 정보 바꾸기

`index.html`에서 `Your Name`, `Your Role`, `Company Name`, `Project One`, `your-email@example.com` 같은 예시 문구를 검색해 본인의 내용으로 교체하세요. 링크를 입력할 때는 같은 요소의 `href="#"`도 실제 주소로 변경하면 됩니다.

## 자동 배포

`main` 브랜치에 변경 사항이 올라오면 `.github/workflows/deploy.yml`이 GitHub Pages에 자동으로 배포합니다. GitHub 저장소의 **Settings → Pages → Build and deployment → Source**는 **GitHub Actions**로 설정되어 있어야 합니다.
